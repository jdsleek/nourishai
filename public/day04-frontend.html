UI/UX · 5 checks

    
DESIGN FOR
A PHONE

    

      
WHO
Busy user, low patience — church, pharmacy, student?

      
HIERARCHY
One H1, one primary CTA; everything else secondary.

      
LAYOUT
Stack on mobile; widen at 768px.

      
TRUST
Title + one-line value prop above the fold.

      
ITERATE
Compare to an app you know; fix one confusion.

    

    
Reject purple-gradient “AI slop.” If it could be any product, re-prompt with your idea in Context.

5-PILLAR
PROMPT

    
Single index.html + embedded CSS · no React · Nigeria / ministry context as needed

    
Role: You are a senior product UI engineer for early-stage apps in Nigeria.

Task: Build ONE file index.html with embedded CSS for my MVP screen. Max 3 sections: Hero, Main, Footer.

Context: [PASTE your QAF idea + who the user is + Day 03 Frontend Stack bullets]

Constraints: mobile-first; semantic HTML; accessible contrast; include ids btn-primary, list-root, insights-panel, and ids on every input; link app.js at bottom; no frameworks; no external paid APIs.

Format: Return only the full index.html source. Add HTML comments explaining layout choices.

    
Students: replace [PASTE…] with your ideation text before you send.
